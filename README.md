# Pari Dagale — Portfolio

Personal portfolio site for Pari Dagale — Computer Educator & Apparel Graphic Designer.

## Structure

```
.
├── index.html              # the entire site (HTML + CSS + JS, single file)
├── assets/
│   └── nap-chief-marvel-avengers-techpack.pdf   # featured project PDF
└── README.md
```

## Running locally

No build step — it's a static site. Just open `index.html` in a browser,
or serve it locally:

```bash
python3 -m http.server 8000
```

then visit `http://localhost:8000`.

## Deploying

This repo is set up to deploy directly with **GitHub Pages** — see the
